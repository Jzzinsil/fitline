어디서 데이터를 가져오는가

추측이 아니라 각 사이트의 robots.txt를 직접 읽고 실제로 요청을 보내본 결과입니다. 초록은 지금 데이터가 들어오고 있는 경로, 노랑은 키·제휴가 필요한 경로, 빨강은 사이트가 명시적으로 금지해서 코드를 만들지 않은 경로입니다.

소스여기서 얻는 것실제로 확인한 접근 방식결과

법·제도 체크리스트 — 플랫폼 설계보다 먼저 정리해야 하는 것

  • 직업안정법 — 국내에서 유료로 사람을 소개·알선하려면 관할 시·군·구에 유료직업소개사업 등록이 필요합니다. 서치펌 창업의 실질적 1단계이고, 등록 전에는 수수료를 받을 수 없습니다.
  • 개인정보보호법 — 이력서·연락처·학력은 개인정보입니다. 수집 목적·항목·보유기간을 밝히고 동의를 받은 범위 안에서만 쓸 수 있고, 동의 없는 제3자(=채용 기업) 제공은 별도 동의 대상입니다. 이 플랫폼의 후보자 프로필은 전부 동의 기반 제출로 설계해야 합니다.
  • 플랫폼 이용약관 — LinkedIn·Blind처럼 로그인 뒤에 있는 데이터를 크롤링하는 건 약관 위반이고, 계정 차단·민사 소송으로 이어집니다. 공개 페이지 크롤링도 약관상 금지된 경우가 많아, 판례가 갈리는 영역에 사업을 세우지 않는 편이 낫습니다.
  • 실무 결론 — 공고는 공공 API + 기업 ATS 공개 엔드포인트로 채우고, 후보자 데이터는 본인 제출 + 공개 논문·GitHub 색인으로 채웁니다. 이 조합만으로 아래 매칭 로직의 입력 7개가 모두 채워집니다.

점수는 어떻게 만들어지는가

실데이터를 넣자마자 드러난 문제가 있습니다. 공고에서 항목을 못 뽑아내면 그 항목이 가중치에서 빠지는데, 그러면 정보가 없는 공고일수록 남은 항목만으로 점수가 쉽게 올라갑니다. 처음 돌렸을 때 NLP 박사 신입의 1순위가 "SW영업/기술지원"이었던 이유입니다. 그래서 판단을 네 층으로 갈랐습니다.

층하는 일안 하면 생기는 일
1. 하드 게이트넘으면 제외학위·영어·경력·딜브레이커 요건 미달을 점수와 무관하게 탈락영어 못하는 후보가 다른 점수 높아서 본사 영어 필수 자리에 추천된다
2. 관련성 게이트연구·도메인 둘 다 0이면 강등연구 주제도 도메인도 안 겹치면 "보낼 근거가 범용 스킬뿐"으로 분류해 기본 화면에서 내림Python 하나 겹쳤다고 모든 후보에게 Security Engineer가 상위로 뜬다 실제로 발생했음
3. 커버리지 보정×(0.5 + 0.5×커버리지)7개 중 3개만 채운 매칭과 7개 다 채운 매칭을 같은 자에 올림정보 없는 공고가 88점으로 1등을 한다 실제로 발생했음
4. 가중치조정 가능남은 항목의 상대적 중요도. 고객사마다 다르니 직접 조정—

아래 슬라이더를 움직이면 매칭 콘솔 순위가 즉시 다시 계산됩니다. 데이터가 없는 항목은 0점이 아니라 "—"로 표시되고 가중치에서 빠집니다. 0점을 주면 없는 사실을 나쁜 사실로 바꾸는 것이라서요.

가중치

하드 게이트

넘으면 제외
학위 < 요구학위박사 필수 공고에 석사를 넣는 건 시간 낭비. 학위 우대는 게이트가 아니라 가중치로 갑니다.
영어갭 ≥ 2본사 보고·영문 면접이 있는 자리에 영어 2단계 아래를 보내면 서류는 통과해도 면접에서 끝납니다.
경력 < 하한−2년신입 채용이 아닌 공고의 연차 하한은 실제로 잘 안 깎입니다.
경력 > 상한+3년과잉 경력은 보상·직급 충돌로 되돌아옵니다. 리드 트랙 공고라면 상한을 따로 둡니다.
딜브레이커 일치후보가 명시적으로 거부한 조건(순환근무, 야간 온콜, 비ML 업무 등)에 걸리면 즉시 제외.
희망연봉 > 상한×1.15게이트가 아니라 경고. 15% 안쪽은 협상 가능 구간으로 두고 초안에 먼저 적어둡니다.

이 로직이 헤드헌터로서 만드는 차이

  • 연구 주제 단위 매칭 — "AI 엔지니어"가 아니라 "대화 요약 박사 → LLM 서빙 팀"으로 붙습니다. 전공명보다 논문 주제가 훨씬 강한 신호이고, 이건 공개 논문 색인에서 무료로 얻습니다.
  • 보낸 이유가 문장으로 남습니다 — 각 매칭의 상위 기여 항목이 그대로 아웃리치 첫 문단이 됩니다. "좋은 자리 있습니다"와 답장률이 다릅니다.
  • 안 보낸 이유도 남습니다 — 차단 사유가 기록되니까, 요건이 바뀌었을 때 그 후보만 다시 꺼낼 수 있습니다.
